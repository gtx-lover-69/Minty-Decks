# Minty Decks!
These are two really cool *(literally)* pocket sized cyberdecks based on the ESP32-C3 and ESP32-S3.

The V1 was unfortunately designed quite shittily with 2mm spacing and holes, rather than 2.54mm.
The V2 or Pro aimed to solve that problem AND added more features like an RGB LED, a bunch more breakout, and a micro SD card slot.

# A story about a waste of 15 Euro
I was so proud of myself for the V1 that immediately upon finishing the PCB, I ordered it via JLCPCB. What a mistake.
